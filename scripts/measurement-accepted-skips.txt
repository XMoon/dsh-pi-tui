# The skip REASONS this qualification accepts on the npm / Linux / Node 24
# runner.
#
# One regular expression per line, matched against the reason a case states
# for not running. A skip whose reason matches NONE of these FAILS the
# aggregate, and so does a skip that states no reason at all.
#
# Two checks, and neither replaces the other:
#
#   - the skip COUNT must equal the committed baseline
#     (`measurement-expected-skipped.txt`);
#   - every skip REASON must match one of the classes below.
#
# A run can have the right count with wrong reasons, and the right reasons
# with a lost case, so both are enforced.
#
# EVERY CLASS HERE NEEDS EVIDENCE FROM THIS ENVIRONMENT. A runner that
# provides a capability must not have a class that tolerates its absence:
# that turns "the tool disappeared from the image" into a green run.
#
# If a class becomes required coverage, the fix is to PROVISION the
# capability on the runner, not to keep accepting the skip.

# The official DSH Optional-bundle installation is not provisioned in the
# runner environment. The case says which package it was looking for. This
# is the whole of the 36-skip population on the npm/Linux/Node 24 runner.
