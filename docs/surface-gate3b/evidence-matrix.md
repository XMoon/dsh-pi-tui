## Reachability and scope notes

- `/tasks`, `/settings`, History, the selected Job workspace, and active Task Quick routes are exercised as mounted application flows in the cited L6 tests; projection-only states are not counted as reachable user surfaces.
- A hidden or zero-grant Task Quick is not an independently focusable destination. The `➜` Full action is a typed navigation target, not a `TaskPanelItem`, real-task count or badge fact.
- The plan-listed `test/settings-theme-boot.test.ts` covers terminal auto-theme boot/listener behavior, and `test/remote-surface-authority-reader.test.ts` covers command/skill metadata; neither is counted as Settings write or Config wire evidence.
- Direct remains the production default; Remote evidence is experimental parity qualification only. No public Extension API or vendored fork source change is included.
- All `M-01..M-07` remain `NOT_RUN`; see the [manual checklist](manual-terminal-checklist.md). No unqualified acceptance follows from VT/CI evidence.
